# CodeAtlas Phase 4 浏览器测试流程

## 测试环境
- 前端：http://localhost:3000
- 后端：http://localhost:8000
- 浏览器：Chromium，通过 agent-browser 执行
- 每轮使用独立测试账号，避免数据互相污染

## A. 可用性与导航
1. 打开首页、聊天、题库、知识库，确认导航和页面可用。
2. 缩小到移动视口，确认无横向溢出。

## B. 注册与登录
1. 合法注册、重复邮箱、无效邮箱和短密码均显示正确结果。
2. 正确登录成功；错误密码和后端不可用时显示友好错误。

## C. 会话与聊天及 RAG
1. 新建会话、发送消息、自动命名、重命名和历史加载均正常。
2. 普通模式 SSE 增量、停止、失败、复制、重新生成和编辑重试均正常。
3. 聊天顶部选择知识库分组，发送问题，预期请求包含 knowledge_group_ids，右侧显示检索引用。

## D. 知识库
1. 创建分组并切换分组，文档计数和列表正确。
2. 上传 HTML 文件，状态最终为 indexed；脚本和样式不出现在预览正文。
3. 打开文档详情显示解析文本；下载接口返回短时效 URL。
4. 不支持扩展名或超限文件被拒绝且不创建文档。
5. 失败文档点击重试重新进入队列。
6. 另一账号访问文档、预览、下载或分组返回 404。

## E. 题库、ACM 与全局异常
1. 打开题库，确认显示系统题目列表、搜索、难度/标签筛选和分页。
2. 打开题目详情，确认题面、样例、约束和开始分析/解题入口可用。
3. 在聊天输入 `@`，确认题目候选可搜索、鼠标选择和上下键/Enter/Escape 操作可用。
4. 切换 ACM 分析模式，未关联题目时显示校验提示；关联后请求带 `mode=acm_analysis` 和 `problem_id`。
5. 切换 ACM 解题模式，确认语言弹窗支持 C++、Java、Python；请求带对应语言。
6. 切换模式后检查历史消息上下文不被当前模式覆盖；重新生成/编辑重试沿用目标消息的题目、模式和语言。
7. 访问不存在路由，确认 404 页面可见。
8. 模拟网络失败，确认全局通知出现且浏览器控制台无阻断错误。
