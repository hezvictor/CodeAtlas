# CodeAtlas 当前开发基线

更新：2026-09-29。本页描述当前仓库代码。

账号、私人题库、模型连接、长期知识库、会话管理、普通/ACM 分析/ACM 解题与引用展示继续保留。ACM 可以关联自己的题目或直接粘贴题面，解题必须指定语言。

聊天共用 LangGraph 单 Agent：固定首次长期混合检索，模型按需通过 search_knowledge/read_knowledge_context 补查。删除了聊天知识库开关及手动长期资料关联功能。临时文件全文使用当前会话的独立非持久缓存，不分块、嵌入或建立知识索引。

后台运行由 PostgreSQL 控制归属、预算和状态，Arq 派发，API 通过 SSE 订阅共享安全进度。停止会取消请求；重连不会创建新运行；临时缓存丢失进入等待补传，用户主动恢复同一运行 ID。答案先校验再显示，不展示隐藏思维链。

模型需要三阶段实测通过：基础聊天、原生工具调用、工具结果回传；只验证基础连接的模型不能准入。上下文容量由服务商规格填写，未知容量不能发送临时全文。

长期上传、版本切换、索引恢复和删除链路继续使用既有实现；已有历史会话文档不自动删除或转换。真实环境迁移与历史数据处置不在本次执行范围。

现有边界仍包括 localStorage 凭证与模型地址的网络出口约束；本次不扩大账号权限或修改认证架构。PDF/OCR、编译执行、在线评测、联网搜索与多 Agent 均不新增。

默认参数、数据期限与词面隐私检测的限制见 [实现说明](agent-rag-architecture.md)。当前验证范围与可重复命令见 [验收记录](agent-rag-acceptance.md)。测试替身只能运行于明确隔离的测试数据库，不能代替真实模型的端到端回答质量评测。
