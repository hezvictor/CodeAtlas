# CodeAtlas 前端页面与交互映射

## 1. 公共布局

顶部导航固定一行：

`CodeAtlas` | 首页 | 聊天 | 题库 | 知识库 | 右侧登录/注册或头像菜单

原型底部 A/B/C 切换器仅用于设计评审，生产实现删除。

## 2. 页面清单

| 页面 | 路由建议 | 核心内容 |
|---|---|---|
| 首页 | `/` | 产品入口、今日会话数、继续上次对话 |
| 聊天 | `/chat` | 左会话栏、中间消息区、底部输入框、右引用栏 |
| 题库 | `/problems` | 搜索、筛选、题目列表、难度/标签、开始分析 |
| 题目详情 | `/problems/:id` | 题面、约束、样例、加入当前会话 |
| 知识库 | `/knowledge` | 分组、搜索、上传、文档列表、处理状态 |
| 文档详情 | `/knowledge/:id` | 解析文本预览、版本状态和元数据 |
| 登录 | `/auth/login` | 邮箱密码登录 |
| 注册 | `/auth/register` | 邮箱密码注册 |

## 3. 聊天页布局

- 左侧：新建会话、最近会话、会话菜单、会话搜索。
- 顶部：当前会话标题、知识库分组选择器和模式选择器。
- 中央：用户消息、助手消息、分析步骤摘要、代码块、复制/重新生成/编辑。
- 底部：附件、输入框、当前模式指示、停止/发送。
- 右侧：回答依据标题、引用切片、页码/章节/代码行定位信息。

## 4. 模式交互

- 普通模式：通用问答。
- ACM 分析模式：显示“不会输出完整代码”的明确提示；输出题意、输入输出、约束、题型、算法和复杂度。
- ACM 解题模式：先弹出语言选择；选择后进入生成流程，输出说明、复杂度和竞赛代码。
- 模式切换只影响下一次请求，不修改历史消息内容。

## 5. 关键状态

聊天：`idle`、`retrieving`、`generating`、`stopped`、`completed`、`failed`。  
文档：`uploaded`、`parsing`、`chunking`、`embedding`、`indexed`、`failed`。  
登录：`anonymous`、`authenticated`、`expired`。

## 6. 响应式规则

- 桌面端显示三栏聊天布局。
- 中等宽度保留左会话栏和右引用栏，缩小间距与字体。
- 手机端隐藏两侧栏，聊天顶部保留知识库分组选择器。
- 不因加载状态改变按钮尺寸；所有按钮需有 disabled/loading 状态。
