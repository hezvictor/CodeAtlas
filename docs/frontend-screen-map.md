# CodeAtlas 页面与交互

更新：2026-09-29。

| 页面 | 当前职责 |
|---|---|
| 首页 | 产品入口、会话统计与继续学习 |
| 聊天 | 会话管理、消息、模式/模型、题目选择、临时全文、真实执行进度与引用 |
| 题库 | 用户题目列表、筛选、详情、增删改、开始分析或解题 |
| 知识库 | 长期分组、上传、冲突处理、版本、进度、预览、下载、索引重试与删除 |
| 模型配置 | 连接、三阶段能力测试、容量与默认模型、Embedding/Reranker |
| 账号 | 登录、注册、个人资料与密码 |

聊天保持左会话、中消息、右来源布局。输入区只保留临时文件与学习模式相关入口。模型下拉仅包含能力实测全部通过的模型。工具反馈可折叠，只显示简短标题、状态及结果条数。

ACM 分析使用题库题面或粘贴题面；ACM 解题需选择语言。切换模式只影响后续请求。等待补传时允许上传临时文件、恢复原运行或结束运行。断线后重新订阅后台运行，不重新发送问题。

引用栏保留真实长期资料来源、位置与删除状态；临时文件只显示全文就绪信息，不显示知识索引完成提示。更多规则见 [实现说明](agent-rag-architecture.md)。
