# CodeAtlas 当前产品范围

更新：2026-09-29。

目标是帮助 ACM/OI 学习者结合自己的题库与长期知识资料理解题目、分析算法、学习解法。账号提供用户隔离；题目与长期资料均属于当前用户。

现有账号、题库、知识库与会话管理继续保留。普通模式、ACM 分析和指定语言的 ACM 解题共享检索与 Agent 执行内核；用户可以选择题库题目，也可以粘贴完整题面。

知识库页面负责长期上传与管理，后台完成解析、结构分块、嵌入和索引。每次聊天固定检索有效长期资料，并允许模型有限补查；来源引用必须对应真实获取的证据。聊天页删除知识库选择和手动长期资料关联。

聊天页保留“＋临时文件”：解析全文用于整个当前会话，只在独立非持久缓存中保存。全文超容量或容量未知明确拒绝；不静默摘要、截断或另建检索索引。缓存丢失时补传并恢复原运行。

聊天显示可折叠的真实执行反馈（检索、模型请求、工具开始/完成/失败），不展示隐藏思维链或原始工具数据。停止、重连、有限重试与后台恢复共用持久控制状态，最终回答经过引用和临时内容校验。

模型配置实测基础聊天、原生工具调用、工具结果回传，清楚标注可用、未验证、未完成、失败或明确不支持；聊天列表只提供全部通过的模型。模型容量与能力测试分开管理。

采用 LangGraph 单 Agent 与两个只读知识工具。不引入 MCP、多 Agent、代码执行、联网搜索、PDF/OCR 或其他未经确认的新功能。旧资料的处理需独立确认，本次不能为删除旧实现而删除用户资料。

完整默认参数、主流程与生命周期见 [实现说明](agent-rag-architecture.md)。
