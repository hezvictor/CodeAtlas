# CodeAtlas 开发路线

更新：2026-09-23。本页区分当前代码与后续工作，历史计划位于 `superpowers/`。

## 当前已实现

账号与个人资料、用户题库、普通和 ACM 聊天、用户模型连接、会话管理、长期与临时文件、知识库分组、异步索引、混合 RAG 检索、可选重排和引用校验。具体行为与限制见 [开发基线](development-baseline.md)。

## 下一步

1. 将聊天运行记录和可订阅事件持久化，支持跨后端实例重连与重启后的明确恢复语义；当前 Redis 租约只解决运行互斥和停止信号。
2. 改造浏览器凭证存储（安全 Cookie/BFF 与相应 CSRF 防护），并对用户配置的模型服务实施可信域名/解析结果约束和网络出口隔离。
3. 把 ACM 静态代码检查真正接入解题结果，再决定是否提供编译运行与在线评测。
4. 建立基于真实 PostgreSQL、Redis、MinIO 和模型服务的集成/端到端测试与 RAG 质量评测。当前离线材料只验证数据契约和词面基线。
5. 明确依赖与容器镜像更新策略、备份恢复步骤、部署监控与故障告警。

公开协作知识库、OCR、图片理解、网页抓取、训练计划、知识图谱、比赛系统等仍是长期规划，当前仓库没有这些功能。
