# 既有认证与对象清理设计记录

本文件仅保留仍适用的认证及存储设计，聊天执行与检索部分已由 [当前实现](../../agent-rag-architecture.md) 替代。

认证使用用户 auth_version：访问令牌包含用户身份、类型、时间、jti 与认证版本；服务端比对用户记录。登出与改密撤销刷新令牌并递增版本，过期/撤销记录按配置清理；数据库只保存刷新令牌摘要。

头像使用格式签名验证和大小限制，新对象提交成功后清理旧对象。长期文档删除立即停止业务可见性，再由后台执行幂等 MinIO 对象清理；缺失对象视为已清理，失败记录与有限重试可观察。

Compose 区分容器内部服务 URL 与浏览器 URL；生产模式拒绝默认密钥和密码。模型凭证加密密钥须长期保留。以上共享认证与存储机制在本次聊天重构中继续使用。
