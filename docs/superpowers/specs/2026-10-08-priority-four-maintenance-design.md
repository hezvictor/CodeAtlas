# CodeAtlas 四项维护改进设计

日期：2026-10-08。依据当前工作区代码制定；实施前重新检查未提交改动。本文只规定修改目标，不执行源码修改、迁移或部署。

## 范围与顺序

四项改进相互独立，建议按“部署说明 → 今日统计 → 闲置能力清理 → 聊天页状态拆分”执行。每项完成并验收后再进入下一项。现有 API 字段、聊天模式、消息持久化策略和 SSE 最终答案语义保持不变。

### 1. 部署说明一致性

`backend/Dockerfile` 当前启动命令为 `alembic upgrade head && exec uvicorn ...`，`backend/tests/test_docker_startup.py` 验证迁移失败时 API 不启动。保留这个运行行为，修正 `docs/agent-rag-architecture.md` 中“容器启动也不自动迁移”的过时说法。文档明确区分 Docker/Compose 自动迁移与 Windows/Linux 原生启动需手动迁移，并写明已有数据升级前备份及迁移失败时的行为。历史设计文件保留历史语境。

### 2. 首页“今日”口径

产品界面使用中文，并在长期文档命名中使用北京时间。首页的“今日会话数”定义为北京时间（UTC+08:00）00:00:00 至次日 00:00:00 的新建会话数。数据库时间仍使用 UTC；查询把北京时间日界转换为 UTC 半开区间。无需新增配置、API 字段或数据库迁移。最近会话排序不变。

### 3. 当前未接入能力的收口

当前聊天调用 `ChatProvider.complete()`，答案经校验后通过 `message.final` 返回；后端没有调用 `stream_chat()` 或 `code_validation.py`，也没有发送 `message.delta`。本轮采用保守收口：移除无生产调用的静态代码验证模块及其孤立测试，移除模型服务商协议和实现中的闲置 `stream_chat()` 及对应孤立测试，清掉前端聊天页的 `message.delta` 分支，并将 SSE 解析器测试改用当前实际事件。保留通用 SSE 解码器、`message.final`、进度事件和历史设计档案。不要把“删除闲置静态验证代码”解释为停止 ACM 解题模式；该模式仍只生成代码，不编译、不执行、不声称通过评测。

若以后要提供真实静态验证或逐 token 展示，需另行设计服务端校验与隐私门禁、模型兼容性、取消、重连及事件协议；不混入本轮维护。

### 4. 聊天页状态拆分

`frontend/src/app/chat/page.tsx` 同时负责 UI、SSE 读取、重连、消息分页及大量运行状态。按行为保持原则，先抽出纯粹的运行事件状态转换，再抽出读取和订阅协调逻辑；页面保留布局、会话动作及业务入口。新模块只消费现有 SSE 协议，不改后端。尤其保留：断线不重发问题；恢复订阅同一 `run_id`；旧终态事件不结束新恢复的运行；最终正文仅在 `message.final` 或持久快照出现；切换会话时旧 reader 被取消且旧结果不覆盖当前页面。

## 验收边界

- 四项分别可测试、可审查、可单独提交；第 4 项在第 3 项后实施以避免抽取已弃用分支。
- 不运行数据库迁移，不修改持久表结构，不部署服务。
- 不引入新前端测试库；使用现有 `node:test`、`tsx` 和 Python `pytest`。
- 真实模型教学质量、浏览器端到端体验及生产数据迁移不由单元测试证明；需要在对应执行阶段另行观察。
