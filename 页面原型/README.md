# 页面原型（Throwaway Prototype）

这是用于确定界面方向的可丢弃原型，不是生产代码。当前原型以 ACM 竞赛学习者为对象，覆盖首页、聊天、私人知识库和登录状态。

## 已确定方向

整体采用 **A / 对话优先**：聊天是核心工作区，左侧管理会话，右侧展示知识库引用和上下文；首页、题库与知识库页面都服务于进入聊天和补充上下文。B、C 仅保留作本轮对比参考，后续实现不以它们作为整体视觉基线。

直接双击 `index.html` 即可打开。通过 URL 参数切换方案：

- `index.html?variant=A`：对话优先，最接近主流 AI 聊天产品
- `index.html?variant=B`：学习工作台，强调学习轨迹和题目分析
- `index.html?variant=C`：知识库优先，强调资料组织和检索

原型内部还提供 `?page=chat`、`?page=library`、`?page=auth` 状态入口。底部黑色切换条仅属于原型工具，后续确定设计方向后应删除。
